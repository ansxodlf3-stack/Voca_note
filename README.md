# Vocab Note (PWA)

휴대폰 홈 화면에 추가할 수 있는 수능 영어 단어장 웹앱입니다.

## 기능
- 모의고사 사진 업로드
- Tesseract.js 영어 OCR
- OCR 단어 주변의 파란색 픽셀을 기준으로 후보 추출
- 추출 후보 확인/수정/제외 및 직접 추가
- 단어 뜻·출처 편집, 암기 체크, 단어 시험
- 브라우저 로컬 저장 및 JSON 내보내기

## 중요: 자동 추출의 한계
파란 동그라미를 컴퓨터 비전으로 완벽히 판별하는 기능은 아닙니다. 사진의 조명, 필기 색상, 동그라미 크기, OCR 위치에 따라 놓치거나 잘못 잡을 수 있습니다. 검정색 표시를 제외하도록 파란색 픽셀만 후보로 삼지만, 저장 전에 반드시 사진과 비교해 주세요.

## 배포 및 홈 화면 설치
PWA는 HTTPS 주소에서 서비스 워커가 동작해야 설치할 수 있습니다.
1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. GitHub 저장소 Settings → Pages → Deploy from a branch → main / root를 선택합니다.
3. 생성된 `https://...github.io/.../` 주소를 휴대폰 Chrome에서 엽니다.
4. Chrome 메뉴(⋮) → '홈 화면에 추가' 또는 '앱 설치'를 누릅니다.

## 데이터
단어 데이터는 현재 기기의 브라우저 localStorage에 저장됩니다. 다른 기기와 자동 동기화되지 않으므로, 단어장 화면의 '내보내기'로 JSON 백업을 보관하세요.

## 실행
정적 웹 호스팅(HTTPS)에서 index.html을 열면 됩니다. OCR 첫 실행에는 인터넷 연결이 필요합니다.
